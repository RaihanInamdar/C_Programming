# C Programming – Assignment 5

This repository contains basic C programming assignments completed as part of my classwork to learn and practice fundamental programming concepts.

## Programs

- **Assignment5_1.c** – Find the greatest among three numbers.
- **Assignment5_2.c** – Check whether a year is a leap year.
- **Assignment5_3.c** – Calculate a grade based on marks.
- **Assignment5_4.c** – Check whether a number is divisible by 3, 5, or both.
- **Assignment5_5.c** – Identify whether a character is a lowercase alphabet, uppercase alphabet, digit, or special character.

## Language Used

- C Programming

## How to Run

1. Install a C compiler such as GCC.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal using **Ctrl + `**.
5. Compile the program you want to run:

   ```bash
   gcc Assignment5_1.c -o myexe
   ```

6. Run the executable:

   **Windows:**
   ```bash
   .\myexe
   ```

   **Linux/macOS:**
   ```bash
   ./myexe
   ```

   Replace `Assignment5_1.c` with the filename of the program you want to run.

## Purpose

To learn and practice conditional statements, functions, relational and logical operators, input validation, and character comparisons in C.
