# C Programming – Assignment 4

This repository contains basic C programming assignments completed as part of my classwork to learn and practice fundamental programming concepts.

## Programs

- **Assignment4_1.c** – Check whether a number is positive, negative, or zero.
- **Assignment4_2.c** – Check whether a number is even or odd using a Boolean function.
- **Assignment4_3.c** – Find the greater of two numbers and check whether both numbers are equal.
- **Assignment4_4.c** – Check voting eligibility based on age.
- **Assignment4_5.c** – Check whether a number is divisible by 5.

## Language Used

- C Programming

## How to Run

1. Install a C compiler such as GCC.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal using **Ctrl + `**.
5. Compile the program you want to run:

   ```bash
   gcc Assignment4_1.c -o myexe
   ```

6. Run the executable:

   **Windows:**
   ```bash
   .\myexe
   ```

   **Linux/macOS:**
   ```bash
   ./myexe
   ```

   Replace `Assignment4_1.c` with the name of the program you want to run.

## Purpose

To learn and practice conditional statements, functions, Boolean values, input validation, and basic decision-making in C.
