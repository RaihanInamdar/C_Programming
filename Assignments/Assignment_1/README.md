# C Programming – Assignment 1

This repository contains basic C programming assignments completed as part of my classwork to learn and practice fundamental programming concepts.

## Programs Included

- **Assignment1_1.c** – Division of two numbers
- **Assignment1_2.c** – Print "Marvollous" five times
- **Assignment1_3.c** – Print numbers from 5 to 1
- **Assignment1_4.c** – Check whether a number is divisible by 5
- **Assignment1_5.c** – Display asterisks (`*`) a specified number of times

## Language
- C

## Purpose
Created for learning, practicing, and strengthening basic C programming concepts.

## How to Run

1. Install GCC on your system.
2. Open the repository folder in VS Code.
3. Open the terminal using `Ctrl + ``.
4. Compile the desired C program:

   ```bash
   gcc filename.c -o myexe
   ```

5. Run the executable:

   ```powershell
   .\myexe
   ```

**Note:** Replace `filename.c` with the name of the C source file you want to run. These commands are for Windows using GCC.
