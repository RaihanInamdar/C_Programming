# C Programming – Assignment 2

This repository contains basic C programming assignments completed as part of my classwork to learn and practice fundamental programming concepts.

## Programs Included

- **Assignment2_1.c** – Display a specified number of asterisks (`*`) using a while loop
- **Assignment2_2.c** – Display a specified number of asterisks (`*`) by decrementing the number
- **Assignment2_3.c** – Print "Hello" if the number is less than 10; otherwise, print "Demo"
- **Assignment2_4.c** – Display a number a specified number of times
- **Assignment2_5.c** – Check whether a number is even or odd

## Language

- C

## Purpose

Created for learning, practicing, and strengthening basic C programming concepts.

How to Run

Install GCC on your system.

Open the project folder in VS Code.

Open the terminal using `Ctrl + ``.

Compile the desired C program:

gcc filename.c -o myexe

Run the executable:

.\myexe

Note: Replace filename.c with the name of the C source file you want to run. These commands are for Windows using GCC.
