# C Programming – Assignment 6

This repository contains basic C programming assignments completed as part of my classwork to learn and practice fundamental programming concepts.

## Programs

- **Assignment6_1.c** – Calculate an electricity bill based on the number of units consumed.
- **Assignment6_2.c** – Check admission eligibility based on marks and age.
- **Assignment6_3.c** – Calculate the payable amount after applying a discount based on the purchase amount.
- **Assignment6_4.c** – Check whether three given sides form a valid triangle.
- **Assignment6_5.c** – Calculate an employee's bonus based on salary and years of service.

## Language Used

- C Programming

## How to Run

1. Install a C compiler such as GCC.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal using **Ctrl + `**.
5. Compile the program you want to run:

   ```bash
   gcc Assignment6_1.c -o myexe
   ```

6. Run the executable:

   **Windows:**
   ```bash
   .\myexe
   ```

   **Linux/macOS:**
   ```bash
   ./myexe
   ```

   Replace `Assignment6_1.c` with the filename of the program you want to run.
